Impostazioni

Configura qui il token GitHub che permette a questo browser di salvare nuove partite e nuovi giocatori. Serve solo a chi inserisce i dati (tipicamente solo a te) — chi consulta il sito non ne ha bisogno.

Token di accesso GitHub

Il token viene salvato solo nel localStorage di questo browser, su questo dispositivo. Non viene mai condiviso con nessuno se non con le API ufficiali di GitHub. Non inserirlo su computer condivisi o pubblici.

Come creare il token (una tantum)

  1. Vai su github.com/settings/personal-access-tokens/new (token "fine-grained", più sicuri di quelli classici).
  2. In "Repository access" scegli "Only select repositories" e seleziona solo il repository di questo sito (es. mtg-elo-tracker).
  3. In "Permissions" → "Repository permissions" imposta "Contents" su "Read and write". Lascia tutto il resto disattivato.
  4. Genera il token e copialo (GitHub lo mostra una sola volta).
  5. Incollalo qui sopra e premi "Salva token", poi "Verifica connessione".

Assicurati di aver prima modificato assets/js/config.js con il tuo username GitHub e il nome del repository, altrimenti la verifica fallirà.
