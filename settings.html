Settings

Configure the GitHub token that lets this browser save new tournaments and players. Only needed by whoever enters the data (typically just you) — visitors don't need it.

GitHub access token

The token is saved only in this browser's localStorage, on this device. It is never shared with anyone except GitHub's official API. Don't enter it on shared or public computers.

How to create the token (one time)

  1. Go to github.com/settings/personal-access-tokens/new ("fine-grained" tokens, safer than classic ones).
  2. Under "Repository access" choose "Only select repositories" and pick only this site's repository (e.g. mtg-elo-tracker).
  3. Under "Permissions" → "Repository permissions" set "Contents" to "Read and write". Leave everything else off.
  4. Generate the token and copy it right away (GitHub only shows it once).
  5. Paste it above and click "Save token", then "Test connection".

Make sure you've already edited assets/js/config.js with your GitHub username and the repository name, otherwise the test will fail.
